# Notebooks

Exploratory and analysis notebooks. These are intentionally minimal stubs — fill them in as you go.

- **`01_data_exploration.ipynb`** — class distributions, audio length stats, speaker/dialogue counts per split.
- **`02_results_analysis.ipynb`** — load `outputs/*/eval/metrics.json` and produce the benchmark table.
- **`03_error_analysis.ipynb`** — confusion matrices, listen to misclassified samples, cluster errors by speaker / class.

Launch with: `jupyter lab notebooks/`
